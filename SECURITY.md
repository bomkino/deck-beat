# Security

Deck Beat sets your slides to your music on your Mac, and reads and writes only the files you choose: the slides and songs you add, its projects and the videos you export. Its one network request is for updates: once a day, and when you choose Check for Updates…, it reads `appcast.xml` from this repository's latest release, and it installs an update only if the update is signed with pitch.dog's update key (see `docs/UPDATES.md`). Please report a security problem privately through this repository's **Security** tab (**Report a vulnerability**) rather than in a public issue, with the version, what you did, what happened, and the smallest case that shows it. A made-up deck and the demo groove are better than your own material.

Releases are ad-hoc signed and not notarized. A binary is supported only when it is published here with a version, a source revision and checksums. Please report a problem with the update signing, or an update that installs without a valid signature, the same private way.
